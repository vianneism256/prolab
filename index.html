Counting Principles

Permutations, combinations, sum rule, and product rule — step by step

Permutations P(n, r)

Ordered arrangements of r items from n distinct items. Order matters.

P(n, r) = n! / (n − r)!

Combinations C(n, r)

Unordered selections of r items from n distinct items. Order does not matter.

C(n, r) = n! / (r! · (n − r)!)

Sum Rule

If tasks are mutually exclusive, total ways = sum of individual ways.

|A ∪ B| = |A| + |B|    when A ∩ B = ∅

Product Rule

If tasks are independent, total outcomes = product of choices at each stage.

|A × B| = |A| · |B|

Binomial Expansion (a + b)n

(a + b)ⁿ = Σ C(n, k) · aⁿ⁻ᵏ · bᵏ   for k = 0 to n

Inclusion-Exclusion Principle

The count of elements in A ∪ B when sets may overlap.

|A ∪ B| = |A| + |B| − |A ∩ B|

Pigeonhole Principle

If n items are placed into k containers, at least one container must hold ⌈n/k⌉ items.

guaranteed maximum in one container = ⌈ n / k ⌉
